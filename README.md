# ATP – IIT Intranet System

## Project Overview

The ATP IIT Intranet System is a group coursework project developed as part of the Advanced Technologies and Practices (ATP) module at the Informatics Institute of Technology (IIT).

The project focuses on developing an integrated university intranet interface that provides students with access to academic information, schedules, student services, campus resources, policies, and support information.

The system combines a login interface with a Student Intranet consisting of seven main sections.

## Main Features

### 1. Login Page
- Student email login interface.
- Google sign-in demonstration option.
- Navigation to the Student Dashboard.

### 2. Student Intranet

The Student Intranet includes the following sections:

- **Overview** – Student dashboard and important information.
- **Schedules** – Student schedule information.
- **Academics** – Academic information and resources.
- **Student Services** – Student service information.
- **Policies and Forms** – Policies and relevant forms.
- **Campus Life** – Campus activities and student life.
- **Help and Support** – Student assistance and support information.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

The project contains:

- Login page.
- Seven Student Intranet pages.
- Shared CSS stylesheets.
- JavaScript files for interface interactions.
- Image and logo assets.

## How to Run the Project

1. Clone or download this repository.
2. Extract the project files if downloaded as a ZIP.
3. Open the project folder.
4. Locate `iit_intranet_portal.html`.
5. Open the file in a web browser.
6. Explore the login interface and navigate through the Student Intranet pages.

## Login Information

The login and Google sign-in options are demonstration features. They simulate the login process and redirect users to the Student Dashboard.

This project does not implement real authentication or production database connectivity.
